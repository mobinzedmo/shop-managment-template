# قالب سیستم مدیریت فروشگاه

یک قالب آمادهٔ فارسی (RTL، تقویم شمسی، تومان) برای مدیریت محصولات، انبار، مشتریان، فاکتور فروش و گزارش‌ها؛ قابل استفاده برای هر نوع فروشگاه.
بدون سرور و بدون Backend؛ همهٔ اطلاعات داخل مرورگر و در IndexedDB ذخیره می‌شود.

## شروع سریع برای فروشگاه شما
1. پروژه را اجرا یا منتشر کنید (پایین‌تر توضیح داده شده).
2. «تنظیمات» ← نام فروشگاه، شعار، نشانی، شماره اقتصادی و ... را وارد کنید (در فاکتور چاپ می‌شوند).
3. «تنظیمات ← ظاهر و تم» یکی از تم‌ها را انتخاب کنید: روشن، تاریک، اقیانوس، جنگل، بنفش، غروب.
4. «تنظیمات ← حذف داده‌های نمونه» و سپس دسته‌بندی‌ها، برندها و محصولات خودتان را وارد کنید.
5. پیشوند کد محصول (پیش‌فرض `P-`) و پیشوند فاکتور (پیش‌فرض `INV-`) از تنظیمات قابل تغییر است.

## امکانات
- داشبورد با کارت‌های آماری، نمودار فروش و سود، پرفروش‌ترین‌ها، هشدار موجودی (همه از داده‌های واقعی)
- محصولات: جدول قابل مرتب‌سازی، جستجو و فیلتر، سود خودکار، کد خودکار، بایگانی هوشمند، دسته‌بندی و برند
- انبار: ورود، خروج، اصلاح موجودی و تاریخچهٔ کامل تراکنش‌ها
- فاکتور: چند محصول، تخفیف ردیف و کلی، ارزش افزوده، پرداخت کامل/ناقص/نشده، شماره‌گذاری خودکار
- ثبت اتمیک فاکتور و موجودی (ذخیره، ویرایش، ابطال با بازگشت موجودی)
- سود واقعی بر پایهٔ قیمت خریدِ ثبت‌شده در لحظهٔ فروش
- خروجی فاکتور بر پایهٔ قالب `reference/faktor-2.xlsx`: چاپ، PDF، PNG، JPG (بدون لوگو)
- گزارش‌ها با بازهٔ زمانی دلخواه، پشتیبان‌گیری و بازیابی JSON، ۶ تم رنگی، PWA و آفلاین

## فونت
برای بهترین ظاهر، فایل‌های `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را در `assets/fonts/` قرار دهید
(<https://github.com/rastikerdar/vazirmatn>). بدون آن‌ها از فونت‌های فارسی سیستم استفاده می‌شود.

## اجرای محلی
```
python3 -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید.

## انتشار روی GitHub Pages
محتوای پوشه را در ریشهٔ یک Repository بگذارید ← Settings ← Pages ← شاخهٔ `main` و پوشهٔ `/ (root)`.
پس از هر به‌روزرسانی فایل‌ها، مقدار `VERSION` را در `sw.js` تغییر دهید تا کش مرورگر تازه شود.

## پشتیبان‌گیری و بازیابی
«تنظیمات ← پشتیبان‌گیری از اطلاعات» فایل JSON می‌سازد و «بازیابی اطلاعات» پس از اعتبارسنجی و تأیید، اطلاعات فعلی را جایگزین می‌کند.

## محدودیت‌های ذخیرهٔ محلی
- اطلاعات مختص پروفایل همان مرورگر است و بین دستگاه‌ها همگام نمی‌شود؛ منظم پشتیبان بگیرید.
- پاک‌کردن اطلاعات مرورگر یا حالت ناشناس، داده‌ها را از بین می‌برد.
- برنامه قفل ورود یا احراز هویت سروری ندارد.
